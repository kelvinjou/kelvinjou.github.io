The challenge

What the project set out to solve

A collaboration with Ph.D. candidate Arthur Caetano and the UCSB Human-AI Integration Lab, XARP is a declarative Python agent toolkit for building extended reality applications. It allows developers to create intelligent agents that can perceive, reason, and act in virtual environments, enabling the creation of immersive and interactive experiences.

The approach

How it was built

Built as a XR experience using Python, FastMCP, Gradio, SmolAgents, C# Unity, Meta XR SDK, Roslyn.
